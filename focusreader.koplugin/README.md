# Focus Reader v1.0.1

Offline focus reading for KOReader. After installing this folder in `koreader/plugins`, restart KOReader and open an EPUB. Go to **Tools → Focus Reader**.

Highlight Focus: 6 colors, 1–5 lines. Spotlight Focus: Reading Window or Reading Guide, 1–5 lines. Uses standard KOReader page-turn inputs and compatible Bluetooth clickers.
